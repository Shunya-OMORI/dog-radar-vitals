## 要約（図を出せない場面用）

- F1 >= 0.80 を保てる範囲での最小 RMSSD 誤差: 13.50 ms (しきい値 0.15, F1 0.853)
- RMSSD 誤差 <= 15.0 ms を保てる範囲での最大 F1: 0.857 (しきい値 0.10, RMSSD 誤差 14.57 ms)
- 理想点からの正規化距離が最小の動作点: しきい値 0.15 (F1 0.853, RMSSD 誤差 13.50 ms)
- F1 が最大の動作点: しきい値 0.10 (F1 0.857, RMSSD 誤差 14.57 ms)
- RMSSD 誤差が最小の動作点: しきい値 0.50 (F1 0.466, RMSSD 誤差 10.20 ms)
- → **2 つの動作点は一致しない。同じしきい値で両方を最良にはできない。**
- 参考: 入力を見ずに一定 RR を出すだけのモデルの RMSSD 誤差 41.34 ms (この値を下回らない限り、変動を捉えたとは言えない)
