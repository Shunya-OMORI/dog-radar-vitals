## 要約（図を出せない場面用）

- F1 >= 0.80 を保てる範囲での最小 RMSSD 誤差: 15.50 ms (しきい値 0.15, F1 0.819)
- RMSSD 誤差 <= 15.0 ms を保てる範囲での最大 F1: 0.598 (しきい値 0.40, RMSSD 誤差 13.00 ms)
- 理想点からの正規化距離が最小の動作点: しきい値 0.15 (F1 0.819, RMSSD 誤差 15.50 ms)
- F1 が最大の動作点: しきい値 0.10 (F1 0.831, RMSSD 誤差 18.16 ms)
- RMSSD 誤差が最小の動作点: しきい値 0.40 (F1 0.598, RMSSD 誤差 13.00 ms)
- → **2 つの動作点は一致しない。同じしきい値で両方を最良にはできない。**
- 参考: 入力を見ずに一定 RR を出すだけのモデルの RMSSD 誤差 41.83 ms (この値を下回らない限り、変動を捉えたとは言えない)
