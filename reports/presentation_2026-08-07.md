## 4. 性能

### 検出性能（Precision–Recall）

![PR曲線](mmecg_comparison/pr_curve_284ep4.png)

- 運用点（しきい値 0.3）: precision 0.81 ／ recall 0.71
- しきい値を下げても recall は 0.83 で頭打ち → **今後の改善余地の所在**（heatmap が立たない見逃しは後処理では救えない）

### タイミング精度（RR 間隔の一致度）

![Bland-Altman](mmecg_comparison/rr_blandaltman_284ep4.png)

- 散布図 r = 0.997（n = 5,739 区間）／ Bland–Altman: **バイアス −0.1 ms**（系統誤差ほぼゼロ），95% 一致限界 ±23 ms

## 5. 工夫した点（ひとことずつ）

1. **教師ラベルの修正**: 自作 R 波検出器が T 波を誤検出しラベル自体が汚染 → NeuroKit2 で全 91 トライアル再ラベル付け
2. **ガウシアン教師幅**: σ = 10/15/20 ms の単一変数比較で，検出率と位置精度の折衷点 σ = 15 ms を採用
3. **サブサンプル重心復号**（今回の主要な工夫）: 5 ms 刻みに量子化されたピーク位置を，姿勢推定の soft-argmax 復号の 1 次元版で連続値に補正．**学習不要の後処理だけで RR-MAE 11.8→8.4 ms・RMSSD-MAE 18.3→10.3 ms・F1 も同時改善**
4. **評価の落とし穴の回避**: 波形相関は「平均波形を出すだけのモデル」でも 0.88 出る／F1 は教師幅を広げるだけで見かけ上改善する — 常に複数指標+ベースライン併記で判断

## 6. エッジ実行性と Raspberry Pi 5

| | 先行実装 | 本手法 |
|---|---|---|
| 前処理+推論（CPU 4 スレッド） | 約 1625 ms／4 秒窓 | **11.6 ms／窓** |
| モデルサイズ（fp32） | 102〜144 MB | **0.13 MB** |

- 計算コスト約 **700 分の 1**．常時稼働の家庭設置デバイスが現実的な規模
- **Raspberry Pi 5 実機検証の準備完了**: 確定モデル+後処理の推論一式を `deploy/rpi5/` に配置し，CPU 4 スレッドでの疎通確認済み（1 窓 9.8 ms）．実機は Tailscale + SSH で WSL の Claude Code から遠隔操作できるようセットアップ予定（`raspberrypi5_plan.md`）

## 7. 残課題と次の一手

1. **イヌのデータへの適用（最優先）** — ヒト公開データでの結果．心拍が速く体毛・体動のあるイヌで成立するかは未検証
2. **recall 0.83 の頭打ち** — 残る見逃しはモデル・入力側の課題（学習側の工夫はこれまで全滅，優先度は慎重に）
3. **評価の安定性** — 11-fold 交差検証への切り替え検討，僅差の判断は複数 seed で
4. **Raspberry Pi 5 実機測定** — レイテンシ・消費電力・温度
